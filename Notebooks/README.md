# Notebooks

This directory contains all Jupyter notebooks used in the TransferBench project.

The notebooks are organized sequentially and should be executed in the following order:

| Notebook | Description |
|----------|-------------|
| 01_Data_Preparation | Dataset loading and preprocessing |
| 02_ResNet18_Feature_Extraction | ResNet18 feature extraction experiment |
| 03_ResNet18_Fine_Tuning | ResNet18 fine-tuning experiment |
| 04_EfficientNetB0_Feature_Extraction | EfficientNet-B0 feature extraction experiment |
| 05_EfficientNetB0_Fine_Tuning | EfficientNet-B0 fine-tuning experiment |
| 06_ViT_B16_Feature_Extraction | Vision Transformer feature extraction experiment |
| 07_ViT_B16_Fine_Tuning | Vision Transformer fine-tuning experiment |
| 08_Benchmark_Report | Final benchmark comparison and report generation |

Run the notebooks in numerical order to reproduce all experiments and results.
