# Utilities

This directory contains the reusable Python modules used across the project.

Modules include:

- dataset.py — Dataset loading and preprocessing
- models.py — Deep learning model factory
- training.py — Training and validation pipeline
- evaluation.py — Evaluation metrics
- visualization.py — Plot generation
- report.py — Benchmark report generation
- paths.py — Project path management

These modules are shared by all notebooks to keep the project modular and maintainable.
